## Структура
- `hello/` — Hello world на C++
- `lib/` — библиотека (`include/` — публичный интерфейс, `src/` — реализации под ОС)
- `test/` — тестовая утилита `bgtest`

## Сборка
macOS / Linux:
```
./build.sh
```
Windows:
```
build.cmd
```
Скрипты делают `git pull`, конфигурацию CMake и сборку.

## Запуск
```
build/bin/hello
build/bin/bgtest <программа> [аргументы]
```
Примеры:
```
./build/bin/bgtest sleep 2
./build/bin/bgtest sh -c "exit 5"
build\bin\bgtest.exe ping -n 3 127.0.0.1
build\bin\bgtest.exe cmd /c exit 5
```

## API
| Функция | Описание |
|---|---|
| `bg_start` | запустить программу в фоне |
| `bg_wait` | дождаться завершения, получить код возврата |
| `bg_try_wait` | проверить без ожидания |
| `bg_pid` | PID процесса |
| `bg_free` | освободить дескриптор |
| `bg_strerror` | текст ошибки |
| `bg_last_os_error` | системный код ошибки (errno / GetLastError) |
