## Структура
- `hello/` — Hello world на C++
- `lib/` — библиотека (`include/` — публичный интерфейс, `src/` — реализации под ОС)
- `test/` — тестовая утилита `bgtest`
- `counter/` — лаба 2: общий счётчик, лог, копии (копии запускаются через `bgprocess`)

## Сборка
macOS / Linux:
```
./build.sh
```
Windows:
```
build.cmd
```
Скрипты делают `git pull`, конфигурацию CMake и сборку.

## Запуск
```
build/bin/hello
build/bin/bgtest <программа> [аргументы]
```
Примеры:
```
./build/bin/bgtest sleep 2
./build/bin/bgtest sh -c "exit 5"
build\bin\bgtest.exe ping -n 3 127.0.0.1
build\bin\bgtest.exe cmd /c exit 5
```

waitpid возвращает упакованное число status. Макрос WIFEXITED проверяет, завершился ли процесс сам, WEXITSTATUS достаёт из status код возврата, а WTERMSIG — номер сигнала, если процесс убили

Возвращаемое значение при WNOHANG:• Если дочерний процесс завершился — функция возвращает его PID (идентификатор процесса).
• Если процессы всё еще работают и изменений нет — функция возвращает 0 (вместо того чтобы ждать завершения).
## Счётчик (лаба 2)
```
./build/bin/counter          # можно в нескольких терминалах
./build/bin/counter --reset  # mac/linux: сбросить общую память и замок
```
Число + Enter меняет счётчик, `q` выход. Лог пишется в `log.txt` в текущей папке.

## API
| Функция | Описание |
|---|---|
| `bg_start` | запустить программу в фоне |
| `bg_wait` | дождаться завершения, получить код возврата |
| `bg_try_wait` | проверить без ожидания |
| `bg_pid` | PID процесса |
| `bg_free` | освободить дескриптор |
| `bg_strerror` | текст ошибки |
| `bg_last_os_error` | системный код ошибки (errno / GetLastError) |
